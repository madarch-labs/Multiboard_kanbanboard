# MultiBoard — доска всех задач

Плагин Kanboard: одна доска с задачами из всех проектов, доступных пользователю.
Можно выбрать проекты и колонки (статусы), отфильтровать задачи по исполнителю, тексту и статусу,
сгруппировать по проекту или исполнителю. Все фильтры хранятся в URL: ссылкой можно поделиться,
и по ней откроется тот же набор фильтров.

## Установка

1. Скопируйте каталог `MultiBoard` в `plugins/` Kanboard. Имя каталога должно быть именно `MultiBoard`.
2. Обновите страницу Kanboard. Плагин появится в **Настройки → Плагины**.

Миграций БД нет. Плагин работает с PostgreSQL, MySQL и SQLite. Совместимость: Kanboard ≥ 1.2.20.

Удаление: удалите каталог `plugins/MultiBoard`.

## Где найти страницу

- меню пользователя (аватар справа вверху) → **Доска всех задач**;
- **Моя панель** → боковое меню → **Доска всех задач**;
- напрямую: `/multiboard` (при включённом URL rewrite) или
  `?controller=MultiBoardController&action=show&plugin=MultiBoard`.

## Права доступа

- **Администратор** (`app-admin`) видит задачи всех активных проектов.
- **Остальные пользователи** видят только активные проекты, где они участники
  (напрямую или через группу). Это тот же список проектов, что в переключателе досок Kanboard.
- Если в URL указан проект, к которому у пользователя нет доступа, он молча отбрасывается.
  Поэтому ссылку можно передавать любому: каждый увидит только то, что ему разрешено.
- Действия над задачей (меню карточки, редактирование) показываются по обычным правилам роли в проекте.

## Как работает доска

### Объединение колонок

У каждого проекта свои колонки. Плагин объединяет их **по названию** без учёта регистра и лишних
пробелов: «На паузе» и «на Паузе» становятся одной колонкой. Названия с разным написанием
(«Выполнен» и «Выполнено») остаются разными колонками. Чтобы их объединить, переименуйте колонки в проектах.

Колонки упорядочены по среднему относительному положению в проектах: первая колонка проекта — 0,
последняя — 1. Поэтому «Ожидающие» идут слева, а «Выполнено» — справа, даже если в проектах разное
число колонок.

Заголовок колонки берётся по самому частому написанию. Рядом с ним указано число задач и иконка
«скрыть» (глаз): она убирает колонку из текущего набора фильтров (меняется URL).

### Карточки

Карточки выглядят так же, как на обычной доске: цвет, исполнитель, аватар, категория, теги,
срок, сложность, подзадачи, комментарии, возраст задачи. Дополнительно на карточке показан проект
(ссылка на его доску). При группировке по проекту эта строка скрыта.

Доска только для просмотра: перетаскивания между колонками нет, потому что колонки разных проектов
не взаимозаменяемы. Задачу можно открыть или отредактировать из меню карточки.

## Фильтры

Панель фильтров открывается и закрывается кнопкой **Фильтры**. Это состояние запоминается в браузере.
Изменения применяются кнопкой **Применить**.

| Фильтр | Параметр URL | Значения | По умолчанию |
|---|---|---|---|
| Проекты | `projects` | id через запятую: `1,4,10`; `none` — ни одного | все доступные |
| Колонки | `columns` | названия через запятую (регистр не важен): `ожидающие,на паузе`; `-` — ни одной | все |
| Поиск | `q` | часть названия задачи или номер (`123` / `#123`) | — |
| Исполнители | `assignee` | через запятую: `me` (текущий пользователь), `none` (не назначено), id пользователей: `me,5,none`; `-` — никто | все |
| Статус задач | `status` | `open`, `closed`, `all` | `open` |
| Группировка | `group` | `none`, `project`, `assignee` | `none` |

Проекты, колонки и исполнители выбираются чекбоксами (множественный выбор). Кнопки
**Выбрать все** / **Снять все** отмечают или снимают всю группу одним кликом.
Если в группе отмечено всё, параметр в URL не пишется. Это значит «все», и в выборку автоматически
попадут проекты, колонки и исполнители, появившиеся позже.

В списке исполнителей есть пункты «Я» и «Не назначено» и пользователи, у которых есть задачи
в выбранных проектах. «Я» в общей ссылке у каждого открывшего означает его самого.

Список колонок в фильтре строится по всем доступным проектам, а на доске показываются только
колонки выбранных проектов.

Параметры со значением по умолчанию в URL не пишутся, поэтому ссылки получаются короткими.

**Скопировать ссылку** копирует текущий URL с фильтрами. **Сбросить фильтры** открывает доску без параметров.

### Примеры

```
/multiboard                                              все задачи всех проектов
/multiboard?columns=ожидающие,на паузе                   только «Ожидающие» и «На паузе»
/multiboard?columns=ожидающие,на паузе,в процессе,готово к проверке
                                                         всё до «Готово к проверке» включительно
/multiboard?projects=1,10&group=project                  два проекта, по строке на проект
/multiboard?assignee=me&group=project                    мои задачи по проектам
/multiboard?assignee=5,7,none                            задачи двух пользователей и неназначенные
/multiboard?status=closed&q=bitrix                       закрытые задачи со словом «bitrix»
```

Кириллицу в URL браузер кодирует автоматически. Обе формы ссылки (закодированная и нет) работают.

## Структура плагина

```
MultiBoard/
├── Plugin.php                      регистрация маршрута, прав, хуков, ассетов
├── Controller/MultiBoardController.php
├── Model/MultiBoardModel.php       права, разбор фильтров, объединение колонок, выборка задач
├── Template/
│   ├── board/show.php              страница и таблица доски
│   ├── board/filters.php           панель фильтров
│   ├── board/task.php              карточка задачи
│   ├── dashboard/sidebar.php       пункт в боковом меню «Моя панель»
│   └── header/dropdown.php         пункт в меню пользователя
├── Assets/css/multiboard.css       только раскладка фильтров и мелочи; остальное — стили Kanboard
├── Assets/js/multiboard.js         сборка URL из чекбоксов, копирование ссылки, скрытие панели
└── Locale/
    ├── en_US/translations.php      английские подписи ключей с префиксом «MultiBoard:»
    └── ru_RU/translations.php
```

Вёрстка повторяет разметку стандартной доски (`#board-container`, `#board`, `.board-column-header`,
`.board-swimlane-header`, `.task-board`) и использует шаблоны ядра `board/task_footer`,
`board/task_avatar`, `task/dropdown`. Поэтому доска наследует тему (светлую/тёмную) и стили
Kanboard и других плагинов, которые цепляются к хукам карточки (`template:board:private:task:*`,
`template:board:task:*`). Работают и стандартные клавиши доски, например `c` — компактный вид.

## Перевод

Строки плагина, которые совпадают со строками ядра (`Filters`, `Apply` и т.п.), используют ключи
с префиксом `MultiBoard:`. Так плагин не перезаписывает переводы самого Kanboard. Чтобы добавить язык,
создайте `Locale/<код_языка>/translations.php` по образцу `ru_RU`.
